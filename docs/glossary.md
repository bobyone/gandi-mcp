# Glossary

One concept, one term, used everywhere (UI, messages, documentation, code,
API). Add a term here before using it. The "UI label" column gives the English
label of a term displayed in the MCP App and its catalog key; its label in each
language is in the table below, generated from the UI catalogs. A term not shown
in the UI says "not displayed".

| Term | Definition | Code identifier | UI label |
| --- | --- | --- | --- |
| Gandi | The registrar and hosting provider whose public API v5 this project uses. | `gandi` | Gandi (never translated) |
| Gandi API | The Gandi public HTTP API, version 5. | `gandi_api` | not displayed |
| Sandbox | The Gandi test environment, where operations have no real effect nor cost; it has its own accounts and tokens. | `sandbox` | Sandbox (`environment.sandbox`) |
| Personal mode | The local MCP server running on the user's computer over `stdio`. | `personal_mode` | not displayed |
| MCP App | The UI provided by the server and rendered by the MCP client. | `mcp_app` | not displayed |
| Tool | An operation exposed by the server to the MCP client. | `tool` | not displayed |
| Account | A Gandi identity configured in the personal mode: a name chosen by the user and a Personal Access Token. | `account` | Account (`field.account`) |
| Default account | The account used when a tool call names no account. | `default_account` | Default account (`status.default`) |
| Personal Access Token (PAT) | A Gandi secret granting API rights to an account; stored in the OS keyring only. | `personal_access_token` | Personal Access Token (`field.token`; never translated) |
| Confirmation | The user's explicit agreement, requested by the server, before a destructive or billable operation, or one needing a secret input. | `confirmation` | not displayed |
| Confirmation option | A yes or no choice the user makes together with a confirmation, outside the model, such as creating a snapshot first. | `confirmation_option` | not displayed |
| Secret input | A secret the user types with a confirmation, outside the model, such as an authorization code (ADR 11). | `secret_input` | not displayed |
| Destructive operation | An operation that deletes or irreversibly changes a Gandi resource. | `destructive` | not displayed |
| Billable operation | An operation that charges the Gandi account (purchase, renewal, transfer). | `billable` | not displayed |
| Environment | The Gandi target of an account: production or sandbox. | `environment` | Environment (`field.environment`) |
| Production | The real Gandi environment, where operations have effects and costs. | `production` | Production (`environment.production`) |
| Read-only account | An account whose write operations are all refused. | `read_only` | Read-only account (`field.readOnly`) |
| Secret store | The operating system keyring, the only place where a Personal Access Token is kept. | `secret_store` | not displayed |
| Preferences | Local settings without any secret: the accounts and the default account. | `preferences` | not displayed |
| Token entry session | A local page to enter a Personal Access Token without the MCP App. | `token_entry_session` | not displayed |
| Operation | A call to Gandi on behalf of an account. | `operation` | not displayed |
| Read operation | An operation that only reads Gandi resources. | `read_operation` | not displayed |
| Write operation | An operation that changes Gandi resources; destructive and billable operations are write operations. | `write_operation` | not displayed |
| Confirmation channel | A way to ask for a confirmation: elicitation or local page. | `confirmation_channel` | not displayed |
| Local page | A temporary page served by the personal mode on `127.0.0.1`, protected by a single-use code, shown to the user through URL elicitation or the browser and never given to the model. | `local_page` | not displayed |
| Pending removal | An account whose removal started and did not finish (failure, cancellation, crash); it can only be removed again, which completes the removal. | `removal_pending` | Removal not finished (`status.removalPending`) |
| Pending confirmation | A confirmation waiting for the user's answer on a local page; its identifier, given back by the model, is valid once and for the same operation only. | `pending_confirmation` | not displayed |
| Untrusted data | Content coming from tool results or free inputs, which may contain prompt injection. | `untrusted` | not displayed |
| Domain | A domain name managed by a Gandi account. | `domain` | Domain (`column.domain`) |
| TLD | The ending of a domain name (`.fr`, `.com`), with its rules: durations and allowed procedures. | `tld` | not displayed |
| Domain contact | A person or structure in one of the roles of a domain: owner, admin contact, tech contact or billing contact; personal data. | `contact` | Domain contacts (`details.contacts`) |
| Owner | The domain contact holding the domain. | `owner` | Owner (`role.owner`) |
| Admin contact | The domain contact handling the administration of the domain. | `admin` | Admin contact (`role.admin`) |
| Tech contact | The domain contact handling the technical matters of the domain. | `tech` | Tech contact (`role.tech`) |
| Billing contact | The domain contact receiving the invoices of the domain. | `bill` | Billing contact (`role.bill`) |
| Quote | The availability and price announced by Gandi for a billable procedure on a name. | `quote` | not displayed |
| Order | A billable procedure confirmed by the user, with its account, paying organization, name, duration and accepted price. | `order` | not displayed |
| Organization | A Gandi entity (person, company, association) that owns resources and can pay for orders; identified by a UUID (`sharing_id` in the Gandi API). | `organization` | not displayed |
| Paying organization | The Gandi organization charged for an order; a default one is stored in the account preferences. | `paying_organization` | Paying organization (`field.payingOrganization`) |
| Asynchronous operation | A procedure Gandi runs later (registration, owner change, transfer), followed by its step and state. | `async_operation` | not displayed |
| Dry run | A simulation of a procedure by Gandi, without effect nor charge. | `dry_run` | not displayed |
| Nameserver | A DNS server declared for a domain. | `nameserver` | Nameservers (`field.nameservers`) |
| Glue record | The IP addresses of a nameserver named inside the domain itself. | `glue_record` | not displayed |
| DNSSEC key | A public key published at the registry to sign the zone of a domain. | `dnssec_key` | not displayed |
| Web redirection | A redirection of a host of a domain to a URL, served by Gandi. | `web_redirection` | not displayed |
| Tag | A label attached to a domain to organize domains. | `tag` | Tags (`details.tags`) |
| Transfer lock | The status forbidding the transfer of a domain to another registrar. | `transfer_lock` | Transfer lock (`column.transferLock`) |
| Authorization code | The secret code required to transfer a domain between registrars. | `authinfo` | not displayed |
| Transfer in | Moving a domain from another registrar to Gandi; a billable procedure. | `transfer_in` | not displayed |
| Transfer out | Moving a domain from Gandi to another registrar. | `transfer_out` | not displayed |
| Owner change | Changing the owner of a domain; may be billable. | `owner_change` | not displayed |
| Trademark claim | The trademark notice to accept before registering some names. | `claim` | not displayed |
| Automatic renewal | The renewal Gandi performs by itself before expiry. | `autorenew` | Automatic renewal (`column.autorenew`) |
| Renewal | Extending the registration of a domain; a billable procedure. | `renewal` | Renew (`action.renew`) |
| Restore | Recovering an expired domain during its redemption period; a billable procedure. | `restore` | not displayed |
| Registration | Buying a domain name that nobody holds yet, for a duration; a billable procedure. | `registration` | Register a domain (`action.register`) |
| Expiry date | The date until which a domain is registered at its registry, stored in UTC. | `expires_at` | Expiry date (`column.expiry`) |
| Availability | Whether a name can be registered, as announced by Gandi with its quote. | `availability` | Check availability (`action.checkAvailability`) |
| LiveDNS | The Gandi DNS service hosting the zone of a domain. | `livedns` | not displayed |
| LiveDNS domain | A domain whose zone is hosted by LiveDNS. | `livedns_domain` | LiveDNS domain (`field.liveDnsDomain`) |
| Zone | All the records of a LiveDNS domain. | `zone` | DNS zone (`tab.zone`) |
| Record | The values of one name and one type in a zone, with their TTL (an RRset in the Gandi API). | `record` | record, inside messages (`action.addRecord`, `feedback.record*`) |
| Record name | The name of a record relative to its zone: `@` for the apex, `*` for a wildcard. | `record_name` | Name (`field.recordName`) |
| Record type | The DNS type of a record (A, AAAA, CNAME, MX, TXT...), among those Gandi supports. | `record_type` | Type (`field.recordType`) |
| Record value | One of the values of a record. | `record_value` | Values (`field.recordValues`) |
| TTL | How long, in seconds, a resolver may cache a record (300 to 2592000). | `ttl` | TTL (seconds) (`field.ttl`) |
| Zone file | A zone written in the standard text format of RFC 1035. | `zone_file` | not displayed |
| Work directory | The only local directory where the personal mode reads and writes zone files and configuration samples. | `work_directory` | not displayed |
| Snapshot | A dated copy of the records of a zone, made on request or automatically. | `snapshot` | Snapshots (`zone.snapshots`) |
| Automatic snapshots | The setting of a LiveDNS domain that makes Gandi take a snapshot before each change. | `automatic_snapshots` | not displayed |
| Signing key | A DNSSEC key with which LiveDNS signs a zone: KSK (flag 257) or ZSK (flag 256); distinct from the DNSSEC key published at the registry. | `signing_key` | not displayed |
| Secondary server | A DNS server, identified by its IP address, allowed to copy a zone. | `secondary_server` | not displayed |
| Zone transfer | The copy of a zone to a secondary server (AXFR). | `zone_transfer` | not displayed |
| TSIG key | A shared secret authenticating a zone transfer; its secret never reaches the model. | `tsig_key` | not displayed |
| Configuration sample | The configuration of a secondary server software (bind, knot, nsd, powerdns) for a TSIG key, given by Gandi; it holds the secret of the key. | `configuration` (`livedns_tsig_config`) | not displayed |
| Domain verification | A TXT or CNAME validation value published by Gandi, for example for an ACME DNS-01 challenge. | `domain_verification` | not displayed |
